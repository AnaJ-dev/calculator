# Calculator

A browser calculator built with vanilla JavaScript, HTML and CSS.

## Features

- Addition, subtraction, multiplication and division
- Multi-digit numbers shown on the display as you type
- `=` to calculate and `AC` to clear
- Divide-by-zero is caught and shows a message instead of breaking

## Tech stack

- Vanilla JavaScript (DOM events, state kept in variables)
- HTML and CSS

## Running it locally

```
git clone https://github.com/AnaJ-dev/calculator.git
```

Then open `index.html` in your browser.

## What I practised

Handling click events, tracking state between button presses, and separating the arithmetic functions from the display logic.
